# MS Crackers Website

A responsive shop website built with **HTML, CSS and JavaScript**. It includes a homepage, collection cards with category filters, about section, fireworks safety guidance, and an enquiry form that opens WhatsApp.

## Files

- `index.html` — page content
- `style.css` — design and responsive layout
- `script.js` — navigation, category filters and WhatsApp enquiry form

## Before publishing

1. Open `script.js`.
2. Change `SHOP_PHONE` to your WhatsApp number with country code and digits only. Example: `919876543210`.
3. Change `SHOP_ADDRESS` to your shop's real address.
4. Edit the shop name and text in `index.html` if you want a different brand name.
5. Replace the sample collection names and illustrations with your real product names, details, and photos. This template does not contain actual stock or prices.

## Preview on a computer

Open `index.html` in a browser. Internet access is required for the optional Google Fonts; the website layout itself is local.

## Publish on GitHub Pages (Android phone or computer)

1. Sign in at [GitHub](https://github.com/).
2. Tap **+** → **New repository**.
3. Give the repository a name such as `ms-crackers-website`, choose **Public**, then create it.
4. Open the repository and choose **Add file** → **Upload files**.
5. Upload `index.html`, `style.css`, and `script.js` from this folder. You can upload `README.md` too.
6. Commit the files.
7. Open the repository's **Settings** → **Pages**.
8. Under **Build and deployment**, select **Deploy from a branch**.
9. Choose branch **main** and folder **/(root)**, then save.
10. Wait a few minutes. GitHub will show your website URL in the Pages section, usually like `https://YOUR-USERNAME.github.io/ms-crackers-website/`.

If GitHub Pages is not shown immediately, refresh the Pages settings after the first commit.

## Important

- The enquiry form opens WhatsApp; it does not store form submissions in a database.
- Never publish private customer information or secret keys in a public repository.
- Sell and promote only products you are legally authorised to sell. Follow applicable local rules and official fireworks safety guidance.
